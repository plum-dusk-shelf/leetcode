# LeetCode Solutions

A collection of my solutions to LeetCode problems, written mainly in C++.

The repository is used for practicing algorithms, data structures, problem-solving techniques, and modern C++.

## Topics

The solutions cover a variety of algorithmic topics, including:

- Arrays and Strings
- Hash Tables
- Two Pointers
- Sliding Window
- Binary Search
- Linked Lists
- Stacks and Queues
- Trees and Graphs
- Recursion and Backtracking
- Greedy Algorithms
- Dynamic Programming
- Sorting
- Bit Manipulation
